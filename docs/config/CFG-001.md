# Purpose

Defines the configurable parameters used by TS-001.

These values are configuration parameters and not business rules.

---

# Parameters

## LOOKBACK_DAYS

Default Value

14

Description

Number of calendar days scanned for Daily Fair Value Gaps.

---

## PTZ_SELECTION_METHOD

Default Value

NEAREST

Options

- NEAREST

Description

When multiple untested Daily FVGs exist, select the nearest one to current market price.

---

## FVG_INVALIDATION

Default Value

FIRST_TOUCH

Options

- FIRST_TOUCH

Description

An FVG becomes invalid immediately after the first touch.
