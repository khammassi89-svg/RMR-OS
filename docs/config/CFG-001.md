# Purpose

Defines the configurable parameters used by TS-001.

These values are configuration parameters and not business rules.

---

# Parameters

## LOOKBACK_DAYS

Default Value

14

Description

Number of calendar days scanned, including the latest completed Daily candle.

The latest completed Daily candle is included in the LOOKBACK_DAYS window.

An FVG belongs to the window only if its Candle C falls within the window.

---

## PTZ_SELECTION_METHOD

Default Value

NEAREST

Options

- NEAREST

Description

When multiple **UNTESTED** Daily FVGs exist, select the one whose nearest boundary is closest to the current market price.

Distance is measured to the nearest boundary only — never the midpoint or the far boundary.

Tie-breaking by newest FVG is defined as business logic in TS-001.

---

## FVG_INVALIDATION

Default Value

FIRST_TOUCH

Options

- FIRST_TOUCH

Description

An FVG becomes invalid on first touch.

A touch is any candle wick touching or entering the gap after Candle C.

A candle close is not required.

Contact with a boundary exactly counts as a touch.

Candles A, B and C are never evaluated.

**Touch detection is performed by TM-001.**

TS-001 consumes the TouchStatus classification produced by TM-001.
