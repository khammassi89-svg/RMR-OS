# Purpose

These values are configuration parameters and not business rules.

---

# Parameters

## LOOKBACK_DAYS

Default Value

14

Description

Number of calendar days scanned for Daily Fair Value Gaps, counted backwards from the latest completed Daily candle, weekends included. An FVG belongs to the window when its third candle (Candle C) falls within these days.

---

## PTZ_SELECTION_METHOD

Default Value

NEAREST

Options

- NEAREST

Description

When multiple untested Daily FVGs exist, select the one whose nearest boundary is closest to the current market price. Distance is measured to the nearest boundary only — never the midpoint or the far boundary. Tie-breaking by newest FVG is defined as business logic in TS-001.

---

## FVG_INVALIDATION

Default Value

FIRST_TOUCH

Options

- FIRST_TOUCH

Description

An FVG becomes invalid on first touch. A touch is any candle wick touching or entering the gap after Candle C; a close is not required, and contact with a boundary exactly counts as a touch. Candles A, B and C are never evaluated. Touch detection is performed by TS-001.
