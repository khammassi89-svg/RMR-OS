# Rule ID

TM-001

---

# Rule Name

Touch Detection

---

# Status

Approved

---

# Purpose

Determine whether a detected Daily Fair Value Gap has been Tested or remains Untested.

This rule performs no detection and no target selection.

It classifies existing RawFVG objects only.

---

# Inputs

- RawFVG
- Daily OHLC Data

---

# Output

Tested

or

Untested

---

# Touch Definition

A Fair Value Gap becomes Tested when the wick of any candle after Candle C touches or enters the gap.

A candle close is not required.

Equality with either boundary counts as a touch.

Candles A, B and C are never evaluated.

The first touch permanently changes the status to Tested.

---

# Processing Rules

1. Receive one RawFVG.

2. Locate Candle C using RawFVG.end_time.

3. Scan every candle after Candle C.

4. Compare the candle wick against the gap boundaries.

5. If any candle touches the gap:

Return Tested.

6. Otherwise:

Return Untested.

---

# Rule Responsibilities

✓ Determine Tested status

✓ Determine Untested status

✓ Apply touch rules

---

# Rule Limitations

Does not:

- Detect FVGs
- Select PTZ
- Calculate distances
- Apply lookback filtering
- Execute trades
