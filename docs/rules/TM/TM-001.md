# Rule ID

TM-001

---

# Rule Name

Touch Detection

---

# Status

Approved

---

# Purpose

Determine whether a detected Daily Fair Value Gap has been TESTED or remains UNTESTED.

This rule performs no detection and no target selection.

It classifies existing RawFVG objects only.

---

# Inputs

- RawFVG
- Daily OHLC candles

---

# Input Requirements

The supplied Daily OHLC candle series shall be in chronological order.

TM-001 processes candles by their position within the supplied series.

"After Candle C" means every candle whose position follows Candle C in the supplied series.

If Candle C cannot be located using `RawFVG.end_time`, the engine shall raise an error.

Duplicate timestamps are not permitted.

The supplied Daily OHLC candles shall conform to DS-001 (Market Data Specification).

---

# Output

TouchStatus

Values:

- TESTED
- UNTESTED

---

# Touch Definition

A Daily Fair Value Gap becomes TESTED when the wick of any completed Daily candle after Candle C touches or enters the gap.

A candle close is not required.

Equality with either boundary counts as a touch.

Candles A, B and C are never evaluated.

The first touch permanently changes the status to TESTED.

A candle touches the Daily Fair Value Gap when:

```
Candle.high >= RawFVG.lower_boundary

AND

Candle.low <= RawFVG.upper_boundary
```

Both gap boundaries are inclusive.

---

# Processing Rules

## Step 1

Receive one RawFVG.

## Step 2

Locate Candle C using `RawFVG.end_time`.

## Step 3

Scan every completed Daily candle after Candle C.

## Step 4

Compare `Candle.high` and `Candle.low` against the Fair Value Gap boundaries.

## Step 5

If any candle touches the gap:

Return **TESTED**.

## Step 6

Otherwise:

Return **UNTESTED**.

---

# Candle Evaluation

TM-001 evaluates only completed Daily candles as defined by DS-001.

TM-001 evaluates only completed Daily candles as defined by DS-001.

TouchStatus is determined only from completed Daily candles that occur after Candle C.

---

# Rule Responsibilities

✓ Determine TESTED status.

✓ Determine UNTESTED status.

✓ Apply touch detection rules.

---

# Rule Limitations

Does not:

- Detect Daily Fair Value Gaps.
- Select the Primary Target Zone.
- Calculate distances.
- Apply lookback filtering.
- Execute trades.
- Analyse lower timeframes.
- Manage trade lifecycle.
