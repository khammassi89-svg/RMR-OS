# Rule ID

TS-001

---

# Rule Name

Primary Target Zone (PTZ) Selection

---

# Status

Approved

---

# Purpose

Identify the single Daily Fair Value Gap (FVG) that will become the Primary Target Zone (PTZ) for the current trading session.

The PTZ is the only Daily FVG used as the starting point for Recursive Manipulation Refinement.

---

# Inputs

- Daily OHLC candles
- Current Market Price

---

# Configuration

Lookback Period

Default:

14 Calendar Days

This value shall remain configurable.

---

# Definitions

## Valid Daily FVG

A valid Daily Fair Value Gap consists of a three-candle imbalance where the aggressive middle candle creates an untraded gap between Candle 1 and Candle 3.

The exact mathematical definition is specified in DR-001.

---

## Untested Daily FVG

A Daily FVG is considered **Untested** only if price has never touched any part of the gap after its creation.

The first touch immediately invalidates the FVG as a PTZ candidate.

---

# Selection Algorithm

Step 1

Scan the previous 14 calendar days.

Step 2

Detect all valid Daily FVGs.

Step 3

Remove every FVG that has already been touched by price.

Step 4

Calculate the distance from the current market price to every remaining Daily FVG.

Step 5

Select the nearest remaining Daily FVG.

Step 6

Assign it as the Primary Target Zone (PTZ).

Only one PTZ may exist at any time.

---

# Output

Exactly one Primary Target Zone.

or

No PTZ Found.

---

# Acceptance Criteria

✓ Uses exactly the previous 14 calendar days.

✓ Ignores every tested Daily FVG.

✓ Chooses the nearest remaining Daily FVG.

✓ Returns one PTZ only.
