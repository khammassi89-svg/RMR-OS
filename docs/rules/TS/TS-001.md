# Rule ID

TS-001

---

# Rule Name

Primary Target Zone (PTZ) Selection

---

# Status

Approved

---

# Purpose

Identify the single Daily Fair Value Gap (FVG) that will become the Primary Target Zone (PTZ) for the current trading session.

The PTZ is the only Daily FVG used as the starting point for Recursive Manipulation Refinement.

---

# Inputs

- Daily OHLC candles
- Current Market Price

---

# Configuration

Lookback Period

Default:

14 Calendar Days

The lookback window is anchored to the latest completed Daily candle and spans exactly the previous 14 calendar days, weekends included.

A Daily FVG belongs to the window only if its third candle (Candle C) falls inside it. Candles A and B may fall outside the window.

This value shall remain configurable via CFG-001 (LOOKBACK_DAYS).

---

# Definitions

## Valid Daily FVG

A valid Daily Fair Value Gap consists of a three-candle imbalance where the aggressive middle candle creates an untraded gap between Candle 1 and Candle 3.

The exact mathematical definition is specified in DR-001.

---

## Untested Daily FVG

Touch detection is owned by TS-001. DR-001 does not compute this status.

A Daily FVG is considered **Tested** when the wick of any candle after Candle C touches or enters the gap. A candle close is not required.

Touch evaluation begins only at the first candle after Candle C. Candles A, B and C are never checked.

Contact with a gap boundary exactly — price equal to a boundary value — counts as a touch.

A Daily FVG is **Untested** only if no candle after Candle C has touched or entered the gap. The first touch immediately and permanently invalidates the FVG as a PTZ candidate.

---

# Selection Algorithm

Step 1

Anchor to the latest completed Daily candle and scan exactly the previous 14 calendar days, weekends included. Include every Daily FVG whose third candle (Candle C) falls inside this window.

Step 2

Detect all valid Daily FVGs using DR-001. Bullish and Bearish FVGs form a single candidate pool.

Step 3

Determine Tested status for each candidate (see Untested Daily FVG) and remove every Tested FVG. This removal happens before any distance is calculated.

Step 4

For each remaining FVG, calculate the distance from the current market price to its nearest boundary. Never use the midpoint or the far boundary.

Step 5

Select the FVG with the smallest nearest-boundary distance. Direction does not influence ranking. If two FVGs are equally near, select the newest one — the later Candle C timestamp.

Step 6

Assign it as the Primary Target Zone (PTZ).

Only one PTZ may exist at any time.

---

# Output

Exactly one Primary Target Zone.

or

No PTZ Found.

---

# Acceptance Criteria

✓ Anchors the window to the latest completed Daily candle and uses exactly the previous 14 calendar days, weekends included.

✓ Includes an FVG in the window only if its Candle C falls inside it.

✓ Owns touch detection; treats any wick touching or entering the gap after Candle C — boundary equality included — as a touch.

✓ Never checks Candles A, B or C for touches.

✓ Removes every Tested FVG before calculating any distance.

✓ Ranks a single pool of Bullish and Bearish FVGs by distance to the nearest boundary.

✓ Breaks distance ties by choosing the newest FVG, using the later Candle C timestamp.

✓ Returns exactly one PTZ, or No PTZ Found.
