# Rule ID

DR-001

---

# Rule Name

Daily Fair Value Gap Detection

---

# Status

Approved

---

# Purpose

Detect all valid Daily Fair Value Gaps (FVG) on the Daily timeframe.

This detector provides the Primary Target Zone candidates used by TS-001.

---

# Timeframe

Daily Only

---

# Inputs

- Daily OHLC Data

---

# Definitions

A Fair Value Gap (FVG) is a three-candle price imbalance created by aggressive market displacement.

The detector supports both Bullish and Bearish Fair Value Gaps.

---

# Bullish Fair Value Gap (BISI)

## Candle Structure

Candle A = First Candle

Candle B = Displacement Candle

Candle C = Third Candle

---

## Mathematical Rule

A Bullish FVG exists when:

Low(C) > High(A)

Equivalent Formula:

Imbalance = Low(C) − High(A)

Imbalance > 0

---

## Gap Boundaries

Upper Boundary

Low(C)

Lower Boundary

High(A)

---

# Bearish Fair Value Gap (SIBI)

## Candle Structure

Candle A = First Candle

Candle B = Displacement Candle

Candle C = Third Candle

---

## Mathematical Rule

A Bearish FVG exists when:

High(C) < Low(A)

Equivalent Formula:

Imbalance = Low(A) − High(C)

Imbalance > 0

---

## Gap Boundaries

Upper Boundary

Low(A)

Lower Boundary

High(C)

---

# Validation

Only three consecutive candles are required.

No additional filters are applied by this detector.

---

# Output

Each detected FVG shall contain:

- Direction
- Start Time
- End Time
- Upper Boundary
- Lower Boundary
- Gap Size
- Status (Untested / Tested)
